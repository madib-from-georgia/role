# Решения проблемы загрузки больших файлов

## Проблема

При загрузке больших файлов (например, 3 555 942 символов) возникают таймауты:
- Загрузка занимает очень много времени
- На удаленном сервере соединение обрывается по таймауту

## Узкие места

1. **Middleware таймаут** - 30 секунд на запрос
2. **Синхронная обработка** - файл читается полностью в память
3. **NLP обработка** - блокирует ответ API
4. **Отсутствие индикации прогресса** - пользователь не видит статус загрузки

---

## 🚀 УРОВЕНЬ 1: Быстрое решение (РЕАЛИЗОВАНО)

### Что сделано

✅ Увеличены таймауты на backend (300 секунд):
- `backend/app/main.py:63` - middleware timeout
- `backend/app/main.py:116-120` - uvicorn settings

✅ Увеличены таймауты на frontend (300 секунд):
- `frontend/src/services/api/index.ts:27-28` - axios timeout

### Эффект

- ✅ Файлы до 10 МБ (~3-4 млн символов) работают
- ❌ Файлы > 10 МБ все еще могут вызывать проблемы
- ⚠️ На медленных соединениях могут быть проблемы

### Когда использовать

- Быстрое решение для большинства случаев
- Локальная разработка
- Хорошее интернет-соединение

---

## ⚡ УРОВЕНЬ 2: Асинхронная обработка (РЕКОМЕНДУЕТСЯ)

### Концепция

1. Файл загружается быстро и сохраняется
2. Обработка (NLP) происходит в фоне через FastAPI BackgroundTasks
3. Frontend опрашивает статус обработки
4. Пользователь видит прогресс в реальном времени

### Что нужно реализовать

#### Backend изменения:

1. **Создать модель ProcessingTask** для отслеживания задач
2. **Модифицировать upload endpoint** для использования BackgroundTasks
3. **Создать endpoint** `/api/tasks/{task_id}/status` для проверки статуса
4. **Добавить функцию** фоновой обработки с callback прогресса

#### Frontend изменения:

1. **Создать хук** `useTaskPolling` для опроса статуса
2. **Обновить компонент** загрузки для показа прогресса
3. **Добавить UI** для отображения прогресса обработки

### Эффект

- ✅ Файлы любого размера
- ✅ Прогресс в реальном времени
- ✅ Не блокирует UI
- ✅ Устойчиво к разрывам соединения
- ⚠️ Требует изменений в БД и backend

### Когда использовать

- **Production окружение**
- Большие файлы (> 10 МБ)
- Длительная обработка (> 30 секунд)
- Нужен feedback для пользователя

---

## 🎯 УРОВЕНЬ 3: Chunked Upload (МАКСИМАЛЬНЫЙ)

### Концепция

1. Файл разбивается на чанки (chunks) по 1-5 МБ
2. Каждый чанк загружается отдельно
3. Backend собирает чанки вместе
4. Поддержка возобновления при ошибке

### Что нужно реализовать

#### Backend:

1. **Endpoint** `/api/projects/{id}/texts/upload/init` - инициализация
2. **Endpoint** `/api/projects/{id}/texts/upload/chunk` - загрузка чанка
3. **Endpoint** `/api/projects/{id}/texts/upload/finalize` - финализация
4. **Модель** UploadSession для хранения состояния
5. **Временное хранилище** для чанков

#### Frontend:

1. **ChunkedUploader класс** для управления загрузкой
2. **Разбиение файла** на chunks с помощью Blob.slice()
3. **Последовательная загрузка** чанков
4. **Обработка ошибок** и retry логика

### Эффект

- ✅ Файлы любого размера (до GB)
- ✅ Возобновление при ошибке
- ✅ Точный прогресс загрузки
- ✅ Параллельная загрузка чанков (опционально)
- ⚠️ Сложная реализация
- ⚠️ Требует дополнительного хранилища

### Когда использовать

- **Очень большие файлы** (> 50 МБ)
- Нестабильное соединение
- Критически важная загрузка
- Нужна возможность pause/resume

## Дополнительные оптимизации

### 1. Nginx конфигурация

Если используете nginx как reverse proxy:

```nginx
# nginx.conf
client_max_body_size 100M;
proxy_connect_timeout 300;
proxy_send_timeout 300;
proxy_read_timeout 300;
proxy_request_buffering off;
```

### 2. Сжатие текста

```python
import gzip
compressed = gzip.compress(content.encode('utf-8'))
```

### 3. Streaming обработка

```python
async def process_file_streaming(file: UploadFile):
    async for chunk in file.stream():
        process_chunk(chunk)
```

### 4. Batch обработка NLP

```python
def process_text_in_batches(text, batch_size=100000):
    for i in range(0, len(text), batch_size):
        batch = text[i:i+batch_size]
        yield process_batch(batch)
```

## Мониторинг

### Backend логирование

```python
import time
import logging

logger = logging.getLogger(__name__)

start = time.time()
result = process_file(file)
duration = time.time() - start

logger.info(
    f"File processed: {file.filename}, "
    f"size: {len(content)} bytes, "
    f"time: {duration:.2f}s"
)
```

```typescript

await uploadFile(file);
const duration = Date.now() - startTime;

console.log(`Upload: ${file.size} bytes in ${duration}ms`);
```

## Troubleshooting

### Таймаут на nginx
→ Увеличить `proxy_read_timeout` и `client_max_body_size`

### Out of Memory
→ Использовать streaming или chunked upload

### Медленная NLP обработка
→ Уровень 2 - асинхронная обработка в фоне

### Разрыв соединения
→ Уровень 3 - chunked upload с retry
