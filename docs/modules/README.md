# Модули системы анализа персонажей

## Структура модулей

Система состоит из 21 модуля: 1 модуль предварительной обработки NLP и 20 специализированных модулей анализа персонажей.

## 🔍 Модуль предварительной обработки

### [`nlp-processing/`](./nlp-processing/)
Модуль обработки естественного языка для извлечения и структурирования данных о персонажах из текста произведения.

## 🎭 Базовые модули анализа персонажей (1-13)

### [`01-physical-portrait/`](./01-physical-portrait/)
**Модуль 1**: Анализ физического портрета персонажа - внешность, манеры, жесты, голосовые характеристики.

### [`02-emotional-profile/`](./02-emotional-profile/)
**Модуль 2**: Определение эмоционального профиля - базовые эмоции, триггеры, способы выражения чувств.

**Модуль 3**: Анализ речевых особенностей - лексика, синтаксис, стилистика, прагматика.

### [`10-acting-tasks/`](./10-acting-tasks/)

### [`11-practical-exercises/`](./11-practical-exercises/)

### [`12-subtext-analysis/`](./12-subtext-analysis/)

### [`13-tempo-rhythm/`](./13-tempo-rhythm/)

## 🔄 Взаимодействие модулей

1. **NLP модуль** обрабатывает исходный текст и извлекает данные о персонажах
2. **Базовые модули (1-13)** анализируют персонажей на основе NLP данных
3. **Психологические модули (14-20)** используют результаты базовых модулей для глубокого анализа
4. **Интеграционный слой** объединяет результаты всех модулей в единый портрет персонажа

## 📊 Форматы данных

- **Входные данные**: Единый JSON формат с данными о персонаже и цитатами
- **Выходные данные**: Структурированный JSON с результатами анализа каждого модуля
- **Интеграция**: Общий формат для объединения результатов всех модулей

## 🛠️ Техническая реализация

Каждый модуль представляет собой независимый компонент с:
- Собственной логикой обработки
- AI промптами для анализа
- Валидацией входных и выходных данных
- Кэшированием результатов
- Метриками качества анализа 

## Подготовка чеклистов для модулей 

- Каждый модуль представлен чеклистом с вопросами на свою тему
- Черновик описан в md формате
```md
# Название чеклиста

## Цель чеклиста

Описание цели

## Секция 1

### Подсекция 1 в секции 1

- [ ] **Вопрос 1**
  *Хинт к вопросу 1*

- [ ] **Вопрос 2**
  *Хинт к вопросу 2*
```
Для того, чтобы подготовить его к импорту в проект, нужен ряд действий

1. Регулярками приводим md к другому формату
   - Добавляется поле "Варианты" - пока пустое
```md
# Название чеклиста

## Цель чеклиста

Описание цели

## Секция 1

### Подсекция 1 в секции 1

- Вопрос 1
    - Варианты: 
    - Подсказка: Хинт к вопросу 1

- Вопрос 2
    - Варианты: 
    - Подсказка: Хинт к вопросу 2
```
1. Запускаем скрипт `npm run checklist-convert-md-to-json docs/modules/<name>/<name>.md docs/modules/<name>/<name>.json`
   — создается json в [специальном формате](./CHECKLIST_TYPES_AND_EXAMPLE.md)
2. Запускаем скрипт `npm run checklist-split-json-to-files docs/modules/<name>/<name>.json docs/modules/<name>/splitted`
   — создается директория `splitted`, в котором json файл разбит на маленькие фрагменты
3. Задаем LLM серию промптов
   — Переписать вопросы, словно это я спрашиваю о себе
   — Добавить к каждому вопросу варианты ответов
   — Добавить к каждому вопросу тип ответа (один или много)
   — Добавить к каждому ответу подсказку, как этот ответ влияет на актера
   — Добавить к каждому ответу упражнения, как добиться такого поведения
4. Запускаем команду восстановления - `npm run checklist-join-files-to-json docs/modules/<name>/splitted docs/modules/<name>/restored.json`
   — Собираем из множества файлов, отредактированных моделью, один общий JSON
5. Редактируем checklists_to_import.txt
   — Раскомментировать строку с именем пересобранного json
6. Запускаем импорт чеклиста в базу данных - `npm run import-checklists`

### Регекспы для очищения чеклистов
1. Удалить "Почему это важно"
```regexp
\*\*Почему это важно:\*\* .+
```

2. Удалить "Примеры..."
```regexp
\*\*Примеры[^:]*:\*\*\n(?:- .+\n?)*

```

3. Удалить "проверямые аспекты"  
```regexp
\*\*(Исследуемые вопросы|Проверяемые аспекты):\*\*
```

4. Создать подсекции   
```regexp
^- \*\*(.+)\*\*$

#### $1
```

5. Создать вопрос   
```regexp
^  - \[ \] \*\*(.+)\*\*$

- $1
```

5. Создать подсказку   
```regexp
^    \*(.+)\*$

    - Подсказка: $1
```

5. Убрать пустую строку между вопросом и подсказкой   
```regexp
^(- .+)\n    \n(    - Подсказка: .+)$

$1\n$2
```

### Промпты для обогащения чеклистов
         
#### Переписать вопросы, словно это я спрашиваю о себе
Есть опросник для актеров. Они готовятся к воплощению персонажа. 
1. Нужно переформулирвоать каждый вопрос так, словно я сам спрашиваю о себе. Например, было: "Какое настроение преобладает у персонажа, когда ничего особенного не происходит?", станет: "В каком я настроении, когда ничего особенного не происходит?"
2. Нужно изменить стиль вопросов, чтобы они стали более человечными, понятными, словно говорит живой человек.
3. Нельзя менять форматирование текста          
4. Читай директорию по одному файлу, не пытайся поместить в контекст всю директорию
         
#### К каждому вопросу добавить ответы
Обогати этот документ ответами на каждый вопрос. 
1. Подумай над наиболее возможными вариантами ответа к каждому вопросу
2. Пойми, это должен быть один ответ или на этот вопрос можно выбрать сразу несколько ответов
3. Запиши в таком формате:

- Насколько богат мой словарный запас - говорю ли я разнообразно или использую одни и те же простые слова?
    - Варианты (один ответ): использую одни и те же, средний лексикон, богатый лексикон
    - Подсказка: Богатство словаря отражает образование, интеллектуальный уровень и социальную среду персонажа

- Повторяю ли я одни и те же слова или умею находить синонимы?
    - Варианты (много ответов): повторяю одни те же, умею находить синонимы, использую мат
    - Подсказка: Вариативность лексики показывает гибкость мышления и речевую культуру

#### Переписать value 
Есть опросник, по которому актер готовится к воплощению персонажа. В опроснике много вопросов про персонажа и варианты ответов. 
1. Во всех файлах этой директории исправь текст в полях к каждому ответу:
- value - нужно переформулировать ответ согласно мужскому и женскому полу
- exportedValue - нужно переформулировать ответ согласно мужскому и женскому полу и сформулировать по-русски правильно в соответствии с вопросом. Например, на вопрос "К какому типу темперамента я ближе всего?" неправильный  ответ "У меня вспыльчивый и страстный (холерик)" — надо написать в "я-манере": "я вспыльчивый и страстный (холерик)". 
2. Очень важно — текст должен быть более человечным, понятным, словно говорит живой человек. 
3. Необходимо, чтобы в exportedValue были такие формулировки, чтобы из ответа было сразу понятно, на какой вопрос отвечает этот ответ. Чтобы не приходилось читать вопрос, чтобы исчерпывающе понять ответ. Чтобы в ответе сразу был бы заключен сам вопрос.

Для вопроса: "Что ограничивает мое эмоциональное развитие?" ты записал в exportedValue: 
```json
"exportedValue": {
    "male": "меня ограничивают внутренние психологические блоки",
    "female": "меня ограничивают внутренние психологические блоки"
}
```
Ответ без вопроса - непонятен. Нужно, чтобы ответ звучал примерно так:
```json
"exportedValue": {
    "male": "Мое эмоциональное развитие ограничивают внутренние психологические блоки",
    "female": "Мое эмоциональное развитие ограничивают внутренние психологические блоки"
}
```
4. Делай предложения в exportedValue такими, словно их говорит живой русский человек
5. К каждому варианту ответа есть hint. Сейчас в поле hint содержится информация о вопросе. Перепиши каждый hint так, чтобы он давал детальные советы про ответ, а не про вопрос. Этот хинт должен содержать информацию для актера, как конкретно этот ответ на вопрос должен повлиять на подготовку к роли.
6. К каждому варианту ответа есть пустое поле "exercise", где будут размещены детальные практические советы для актеров. Прочитай вопрос, для каждого ответа прочитай поле hint и создай в соседнем поле  exercise детальные упражнения, чтобы тренировать то, что написано в ответе и в hint. Следуй принципам: 
- Конкретные измерения
- Физические упражнения
- Технические приемы
- Физиология
- Звуковые характеристики
- Проверочные методы
